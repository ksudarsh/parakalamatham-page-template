# ParakalaMatham Page Template

Starter template for `parakalamatham.org` custom page projects.

## Intended Use
- Build a custom HTML fragment for a WordPress page
- Use the WordPress page template `Unboxed Content`
- Do not build a full standalone website unless explicitly requested

## Included Files
- `page.html` - starter WordPress-safe embeddable HTML fragment
- `Requirements.md` - project brief starter
- `stakeholder-questionnaire.md` - editable questionnaire for collecting facts
- `stakeholder-questionnaire.docx` - Word version of the questionnaire
- `PARAKALAMATHAM-WEB-RULES.md` - technical rules for this site

## Recommended Workflow
1. Copy this repo for a new institution or initiative.
2. Rename the folder/repo to the new project slug.
3. Add images and source material.
4. Update `Requirements.md`.
5. Get the questionnaire filled by the stakeholder.
6. Build or revise `page.html`.
